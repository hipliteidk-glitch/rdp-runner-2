# Run Left - countdown APK

A one-screen Android app that shows the time left until a deadline. Built for the
GitHub Actions run **39528621597** (`Roblox Player test (RDP + Tailscale)`), whose
keep-alive window ends at **2026-10-21 13:29:14 UTC**.

`RunLeft.apk` (87 KB, debug-signed) is the installable artifact.

## What it shows

- A big `HH:MM:SS` countdown, ticking live, turning red with `EXPIRED` at zero.
- The target in local time, in UTC, and the current time in both.
- `Set target` - pick any date/time (local); the value is persisted.
- `Run end` - jump back to the default target of run 39528621597.

## Install

```powershell
adb install RunLeft.apk
```

It is signed with a local debug key (`out/debug.keystore`, `androiddebugkey` /
`android`), so it installs over anything else signed with that key - but it cannot
be published to Play as-is.

## Rebuild

No Gradle, no network: `aapt2` -> `javac` -> `d8` -> `zipalign` -> `apksigner`,
driven by `build.ps1`.

```powershell
pwsh -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

Prerequisites:

| Tool | Where |
| --- | --- |
| aapt2 / d8 / zipalign / apksigner | `C:\Android\android-sdk\build-tools\34.0.0` |
| android.jar (API 34) | `C:\Android\android-sdk\platforms\android-34` |
| JDK 17 | `C:\Users\RDP\AppData\Local\Temp\1\opencode\jdk17\jdk-17.0.20.1+1` |

The box's default JDK is 8, which `d8` rejects (`UnsupportedClassVersionError`),
hence the Temurin 17 download.

## Layout

| Path | What |
| --- | --- |
| `src/MainActivity.java` | the whole app - UI is built in code, no XML layouts |
| `AndroidManifest.xml` | `dev.opencode.runleft`, minSdk 24, targetSdk 34 |
| `res/values/` | colours, theme, app name |
| `res/mipmap-*/` | launcher icons generated by `make_icons.py` (Pillow) |
| `make_icons.py` | regenerates the icons |
| `build.ps1` | the build |

## Notes

- No network, no permissions, no tracking: the app is a pure local countdown.
- The target is stored in `SharedPreferences` (`runleft` / `target_ms`).
- `minSdk 24` so `CountDownTimer`, `setLetterSpacing` and the dark
  `Theme.Material` behave the same everywhere.
